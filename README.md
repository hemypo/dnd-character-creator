# D&D 2024 Генератор Персонажей («Character Weave / HeroForge AI»)

> **Веб-сервис для быстрой генерации и ведения персонажей 1-го уровня по обновлённым правилам Dungeons & Dragons 2024 (Revised 5e / SRD 5.2).**  
> Создан для комфортной игры за живым столом («сервис для своих»): без изучения 300+ страниц правил, с уникальными механиками своими словами, атмосферным портретом и официальным бланком PDF.

---

## ✨ Ключевые возможности

1. **Интуитивный выбор архетипов вместо рутины расчетов**:
   - 3 простых шага: **Роль** (Танк, Ударник, Заклинатель, Поддержка), **Источник силы** (Воинский, Теневой, Божественный, Арканный) и **Наследие/Раса** (Человек, Дварф, Эльф, Полурослик и др.).
   - Автоматический расчет валидного шасси 1-го уровня: класс, характеристики (Ability Scores), предыстория с бонусами к характеристикам (+2/+1 по правилам 2024), черта происхождения (Origin Feat), КД (AC), хиты (HP) и стартовое снаряжение.

2. **Балансировка пользовательских способностей («Balance Cards»)**:
   - Игрок описывает любую безумную или колоритную идею своими словами (например: *«Хочу плевать кислотой, когда получаю урон»* или *«Удар щитом сбивает с ног»*).
   - Арбитр баланса трансформирует запрос в 2–3 строгих варианта механик, строго заякоренных в официальный бюджет **Origin Feats** или заговоров D&D 2024 с разумными ограничениями (1 раз за короткий/долгий отдых или трата реакции). Никакого неконтролируемого читерства и споров с Мастером.

3. **Генерация портрета («D&D-ify Yourself»)**:
   - Загрузка селфи/фото для превращения в фэнтезийный портрет выбранной расы и класса.
   - Бесплатная интеграция с **SubNP Free API** (современная модель **Flux**).
   - Надежный офлайн-фоллбек: динамические векторные SVG-гербы и галерея готовых пресетов без расхода трафика и API-ключей.

4. **Атмосферная предыстория на русском языке**:
   - 2–3 связных литературных абзаца, органично сплетающих наследие персонажа, его прошлое ремесло, боевое призвание и причину пробуждения особой способности.

5. **Интерактивный мобильный лист для игры за столом**:
   - Оптимизирован для экранов смартфонов (крупные тач-таргеты 48×48px по стандарту WCAG).
   - Интерактивный счетчик текущих хитов (`+` / `-`) с динамической индикацией здоровья.
   - Боевые действия, бонусы к атакам, кубы урона и свойства оружейных приемов 2024 года (**Weapon Masteries**: *Topple*, *Push*, *Vex*, *Nick*, *Slow*).
   - Быстрый доступ к карточке особой механики и предыстории.

6. **Официальный PDF-бланк D&D 2024 в 1 клик**:
   - Прямой экспорт в стандартный печатный бланк листа персонажа.
   - Полная поддержка кириллицы (шрифт Arial через `@pdf-lib/fontkit`).
   - Встроенный портрет героя или геральдический герб.

7. **Хранение и шеринг по короткому ключу (`HERO-XXXX`)**:
   - Каждый герой получает уникальный секретный код (например, `HERO-7788`).
   - Модальное окно шеринга: мгновенное копирование кода или прямой ссылки для отправки Мастеру (DM) или друзьям.
   - Локальное кэширование в браузере (`localStorage`) и серверное хранилище в JSON.

## 🚀 Быстрый старт

### Требования
- **Node.js** версии 18.17+ или 20+
- **npm** версии 9+

### Установка и запуск

1. **Клонируйте репозиторий и установите зависимости:**
   ```bash
   git clone <repo-url>
   cd dnd-character-creator
   npm install
   ```

2. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env.local
   ```
   *(Сервис полностью функционален «из коробки» без указания API-ключей благодаря встроенным детерминированным генераторам и офлайн-моделям).*

3. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:3000](http://localhost:3000) в браузере.

4. **Запуск тестов:**
   ```bash
   npm test
   ```

5. **Сборка для продакшена:**
   ```bash
   npm run build
   npm start
   ```

## ⚙️ Конфигурация окружения (`.env.local`)

| Переменная | Описание | Значение по умолчанию |
|------------|----------|------------------------|
| `OPENROUTER_API_KEY` | Ключ OpenRouter для нейросетевых текстовых моделей | *(Опционально)* |
| `OPENROUTER_TEXT_MODEL` | Текстовая модель OpenRouter | `google/gemma-4-31b-it:free` |
| `GEMINI_API_KEY` | Google Gemini API ключ (альтернатива для текста и визуала) | *(Опционально)* |
| `SUBNP_API_URL` | Бесплатный API генерации изображений Flux | `https://subnp.com/api/free/generate` |
| `DATA_DIR` | Путь к директории хранения персонажей | `./data` |
| `PORT` | Порт локального веб-сервера | `3000` |

## 🏗 Архитектура и стек технологий

```
dnd-character-creator/
├── src/
│   ├── app/                    # Next.js 14 App Router (страницы и API-эндпоинты)
│   │   ├── api/                # Серверные роуты (/characters, /export-pdf, /generate-*)
│   │   ├── character/[key]/    # Интерактивный лист персонажа по ключу
│   │   ├── create/             # Пошаговый мастер создания героя (Wizard)
│   │   ├── layout.tsx          # Корневой макет с темой Dark Fantasy
│   │   └── page.tsx            # Главная витрина и поиск по ключу HERO-XXXX
│   ├── components/
│   │   ├── sheet/              # Компоненты листа: InteractiveSheet, ActionCards, ShareKeyModal
│   │   └── wizard/             # Компоненты мастера: ArchetypeSelector, CustomMechanic, PhotoUploader
│   ├── lib/
│   │   ├── ai/                 # Модули ИИ: balanceArbiter, backstoryGenerator, portraitPipeline
│   │   ├── dnd2024/            # Ядро правил D&D 2024: rulesEngine, archetypes
│   │   ├── pdf/                # Генератор официального PDF (pdf-lib, fontkit)
│   │   └── storage/            # Атомарное JSON-хранилище персонажей characterStore
│   └── types/                  # Строгая типизация TypeScript (character, balance, archetype)
└── tests/
    ├── ai/                     # Тесты генераторов предысторий, баланса и портретов
    ├── components/             # Тесты UI-компонентов (Wizard, InteractiveSheet)
    ├── dnd2024/                # Тесты механик 2024 и математики характеристик
    ├── e2e/                    # Сквозной интеграционный тест жизненного цикла
    ├── pdf/                    # Тесты экспорта PDF с кириллицей и портретами
    └── storage/                # Тесты хранилища и поиска по ключу
```

- **Frontend & Backend**: Next.js 14 (App Router, Server & Client Components).
- **Стилизация**: Tailwind CSS (эстетика Dark Fantasy: глубокий сланец `bg-slate-950`, янтарно-золотые акценты `amber-400`, адаптивная верстка).
- **Иконки**: `lucide-react`.
- **Генерация PDF**: `pdf-lib` + `@pdf-lib/fontkit` с внедрением кириллического шрифта TrueType и сжатием изображений.
- **Тестирование**: `vitest` + `@testing-library/react` (100% прохождение тестов, строгая методология TDD).
- **Типобезопасность**: Полная валидация без `any` и `@ts-ignore` (`strict: true`).
